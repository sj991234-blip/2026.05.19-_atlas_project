문서 소스 안내

원본 자료 전체는 별도 문서로 구성되었습니다. 이 페이지에서는 원본 텍스트를 확인하거나 필요 시 복사하여 활용할 수 있습니다.

분량이 많아 홈페이지에서는 별도 페이지로 이동하도록 구성하여 사용자와 유지보수성을 모두 고려했습니다.

문서 위치

현재 프로젝트 루트의 assets/data/prompt-atlas.json과 내부 페이지에서 프롬프트 목록이 로드됩니다.

원본 텍스트는 추후 필요에 따라 추가로 옮겨서 관리할 수 있습니다.

아래 예시는 프롬프트 검증 및 문서화 워크플로우에서 참고할 수 있는 텍스트 샘플입니다.

문서 제목: 프롬프트 검증 라이프사이클

1. 목표 정의
  - 작업 대상, 기대 결과, 제한 조건을 명확히 설정합니다.
2. 상황 분석
  - 현재 입력 텍스트의 역할, 맥락, 출력 형식을 파악합니다.
3. 프롬프트 작성
  - 명확한 역할, 작업 지시, 입력/출력 조건, 예시를 포함합니다.
4. 검증 및 개선
  - 출력 결과를 평가하고, 부정확성, 누락, 편향을 보완합니다.
5. 문서화
  - 최종 프롬프트, 검증 결과, 개선 히스토리를 함께 기록합니다.
